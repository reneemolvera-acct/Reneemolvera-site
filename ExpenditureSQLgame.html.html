Expenditure Cycle ERD Challenge

ACCT 40223 · Accounting Information Systems · Reading an ERD to plan a query

Plan the query from the ERD

Management needs information from the company's expenditure cycle database — the purchase orders, vendors, receiving reports and vendor invoices behind every purchase. For each question, study the ERD and decide which tables and which variables (columns) you would use to write the SQL query.

1 · Read the questionEach answer box tells you how many items it needs, e.g. Drop 2 variables
2 · Drag from the ERDDrag a table name (colored header) or a variable (row) into the box. On a tablet, tap the item, then tap the box.
3 · CheckCorrect items turn green, wrong ones turn red. Fix them and check again, then see the SQL.

Tip: hover over a variable in the ERD to light up the relationship lines that connect it to other tables.
